AudLabs API

The AudLabs API gives developers programmatic access to 190+ professional AI voices. Generate natural-sounding speech for any application — simple REST API, no complex setup required.

Get Your API Key →

Authentication

All API requests require your API key passed as a request header. Get your key from the Developer Portal.

Header
x-api-key: aud_your_api_key_here

// Or as Bearer token:
Authorization: Bearer aud_your_api_key_here
Keep your API key secret. Never expose it in client-side JavaScript, mobile app code, or public repositories. Use it only in server-side code.

Base URL

https://app.audlabs.io/api/v1

Generate Voice

POST /api/v1/generate

Convert text to speech. Returns an MP3 audio file as binary data.

Request Body

ParameterTypeDescription
textrequiredThe text to convert to speech. Maximum 50,000 characters per request.
voice_idrequiredThe voice to use. See Voice IDs section below.
speedoptionalSpeech speed. Range: 0.5 to 2.0. Default: 1.0
pitchoptionalPitch adjustment. Range: -12 to 12. Default: 0
volumeoptionalVolume level. Range: 0.1 to 2.0. Default: 1.0
formatoptionalOutput format. Options: mp3, wav. Default: mp3

JavaScript Example

JavaScript
const response = await fetch('https://app.audlabs.io/api/v1/generate', {
  method: 'POST',
  headers: {
    'x-api-key': 'aud_your_api_key_here',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: 'Hello world. This is a test of the AudLabs API.',
    voice_id: 'English_CaptivatingStoryteller',
    speed: 1.0,
    format: 'mp3'
  })
});

const audioBlob = await response.blob();
const audioUrl = URL.createObjectURL(audioBlob);
const audio = new Audio(audioUrl);
audio.play();

Python Example

Python
import requests

response = requests.post(
  'https://app.audlabs.io/api/v1/generate',
  headers={
    'x-api-key': 'aud_your_api_key_here',
    'Content-Type': 'application/json'
  },
  json={
    'text': 'Hello world. This is a test of the AudLabs API.',
    'voice_id': 'English_CaptivatingStoryteller',
    'speed': 1.0
  }
)

with open('output.mp3', 'wb') as f:
  f.write(response.content)

List Voices

GET /api/v1/voices

Returns a list of all available voices with their IDs and metadata.

JavaScript
const response = await fetch('https://app.audlabs.io/api/v1/voices', {
  headers: { 'x-api-key': 'aud_your_api_key_here' }
});
const data = await response.json();
console.log(data.voices);

Error Codes

StatusCodeDescription
401UnauthorizedMissing or invalid API key. Check your x-api-key header.
402Payment RequiredNo active subscription or monthly credits exhausted. Subscribe at platform.audlabs.io.
429Rate LimitedExceeded 5 requests per minute. Slow down your request rate.
400Bad RequestMissing required parameters or invalid values in request body.
503Service UnavailableVoice generation temporarily at capacity. Retry after a few seconds.
500Server ErrorInternal error. Contact hello@audlabs.io if this persists.
